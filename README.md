## 安装：照着这 5 步做

### 第 1 步：先关掉游戏

如果正在玩，先保存，再正常退出游戏。不要只把游戏窗口缩小。

### 第 2 步：把补丁解压出来

找到下载好的“The Séance of Blake Manor布莱克庄园降灵会 简体中文补丁.zip”。

对它点鼠标右键，选择“全部解压”或“解压到……”，等解压完成。

打开解压出来的文件夹，找到 **Install.cmd**。如果电脑隐藏了文件后缀，它可能只显示为 **Install**。

补丁放在桌面或下载文件夹都可以。不用把补丁搬进游戏文件夹，也不用自己复制替换游戏文件。请从解压后的文件夹里运行，不要在压缩包里直接双击安装。

### 第 3 步：找到游戏放在哪儿，并复制地址

打开 Steam，在“库”里找到 The Séance of Blake Manor。

右键点游戏名字 → 点“管理” → 点“浏览本地文件”。

这时会弹出游戏的文件夹。点击窗口最上方的地址栏，按 **Ctrl+A** 全选，再按 **Ctrl+C** 复制。

这里复制的是你自己电脑上的游戏文件夹地址，不需要手动把那一长串地址打出来。

### 第 4 步：双击安装，把刚才的地址粘进去

回到第 2 步解压出来的补丁文件夹，双击 **Install.cmd**（或 Install）。

会弹出一个黑色窗口。看到“粘贴游戏安装目录”的提示后：

**按 Ctrl+V 粘贴刚才复制的地址，再按回车。**

如果 Ctrl+V 没有粘贴出来，可以在黑窗口里点一下鼠标右键，再按回车。

### 第 5 步：看到“安装完成”，再开游戏

等黑窗口显示 **“安装完成”**。

看到“Press any key to continue”时，意思是“按任意键继续”；按一下回车就能关闭安装窗口。

然后像平时一样，从 Steam 启动游戏。**进游戏就应该是简体中文，不用再选语言。**

如果窗口显示的是“失败”，就还没有安装成功，请先看下面的“装不上时怎么办”。

## 另外几个操作：需要时再看

**想让调查不扣时间：**

先保存并退出游戏，然后双击补丁文件夹里的 **Manual-Time.cmd**。和安装时一样，粘贴游戏文件夹地址，再按回车。

开启后，调查和对话不再自动扣时间。想让时间往后走时，在正常探索画面按 **P**，打开等待菜单，选好时间并确认。剧情本身推动的时间仍会变化。

**想恢复游戏原来的计时方式：**

先保存并退出游戏，再运行一次 **Install.cmd**，粘贴游戏文件夹地址并回车。汉化会保留。

**想卸载汉化、恢复原版：**

先保存并退出游戏，再双击 **Uninstall.cmd**，粘贴同一个游戏文件夹地址并回车。看到“卸载完成”后，再启动游戏。

这几个操作都不需要你删除自己的存档。安装器会保留存档和画质、音量、按键等个人设置。

## 装不上时怎么办

**提示游戏还在运行：**先完全退出游戏，再重新安装。

**提示找不到游戏：**重新按第 3 步，从 Steam 打开游戏文件夹并复制地址。不要选择解压出来的补丁文件夹。

**提示版本不支持，或文件已经被修改：**可能是游戏更新了，或装过其他补丁。先不要手动覆盖，查看“详细说明与故障处理.txt”。

**提示缺少 simhei.ttf：**电脑缺少补丁需要使用的黑体字体，安装器会停止。处理办法见“详细说明与故障处理.txt”。

**语言选项里写着 French／法语：**这是补丁使用的原游戏语言位置，显示中文时属于正常情况。安装后不用去改它；想切回英文时，可以选择 English。
